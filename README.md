## 問題回答

### 問題一：為什麼 `"4"` 要先轉成數字，才能用於本題的分攤計算？

因為 `"4"` 是字串（`str`），不是可以直接做算術運算的數字型別。如果拿總金額去除以字串 `"4"`，Python 會直接發生 `TypeError` 錯誤而無法計算；轉成整數（`int`）之後，才能正常做除法分攤給每個人。

### 問題二：如果先扣折價券，再依剩餘餐費計算服務費，第一組的應付總額會變成多少？為什麼和題目規定的結果不同？

如果先扣 100 元折價券，剩餘餐費是 `1,200 - 100 = 1,100` 元，再算 10% 服務費是 `1,100 × 0.10 = 110` 元，應付總額會變成 `1,100 + 110 = 1,210` 元。

這和題目規定的 `1,220` 元不同，是因為計算順序改變了：原本是對完整的 `1,200` 元算 10% 服務費（`120` 元），再扣 `100` 元折價券（`1,200 + 120 - 100 = 1,220` 元）；先扣折價券會讓服務費少算 `10` 元（`100 × 0.10 = 10` 元），所以總額少了 `10` 元。
